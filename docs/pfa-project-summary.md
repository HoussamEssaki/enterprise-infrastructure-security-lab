# Academic PFA reference — infrastructure and security

## Context

This portfolio document summarizes the themes of a multi-site, virtualized infrastructure PFA carried out during an academic internship. It is intentionally high-level and sanitized; it is not an operational deployment guide.

## Workstreams represented

- Virtualized infrastructure and laboratory environments.
- Network segmentation, switching and redundancy concepts.
- Perimeter security and firewall policies.
- Windows infrastructure services.
- DMZ and Linux services.
- Storage, backup and recovery.
- Monitoring and security-event visibility.
- Workflow automation and notification.

## Engineering lessons

1. Infrastructure diagrams should reflect the actual deployment and be versioned.
2. Redundancy is a design claim until failover has been observed and measured.
3. Backup success is not recovery proof; restoration and integrity checks matter.
4. Monitoring should be validated end-to-end from source to alert.
5. Security controls require evidence, scope and maintenance.
6. Capacity constraints influence what can be demonstrated in a virtual lab.
7. Project documentation should distinguish configuration, test and outcome.

## Portfolio boundary

This summary is not a copy of employer or client documentation. It excludes operational identifiers, private IP addressing, keys, credentials, detailed firewall rules, raw configurations and sensitive screenshots. It does not claim certification or production readiness.
