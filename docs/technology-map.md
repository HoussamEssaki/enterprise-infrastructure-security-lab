# Technology map

A concise map of technology families and the skills this project is intended to demonstrate.

| Domain | Technology family | Learning / evidence focus |
|---|---|---|
| Virtualization | VMware ESXi / vCenter | VM lifecycle, resource planning, administration |
| Network lab | PNETLab | Topology simulation and documentation |
| Switching | Cisco | Segmentation, redundancy, traffic flow |
| Firewall | FortiGate | Policy concepts, logs, boundary controls |
| Systems | Windows Server | Identity and core services |
| Linux | RHEL / Linux | Service operation, host administration |
| Storage | TrueNAS / ZFS / NFS | Storage concepts and access controls |
| Backup | Veeam | Backup policy and restore validation |
| Cloud storage | Azure Blob | Retention and immutable-storage concepts |
| Monitoring | Zabbix / Grafana | Health, metrics and dashboards |
| Security telemetry | Wazuh | Defensive host telemetry |
| Log analysis | Splunk | Concepts and exploratory work; scope clearly labeled |
| Workflow | n8n / PostgreSQL | Event workflow and notification |

Do not treat this list as proof that each technology is currently running in the repository's future standalone lab. See [implementation status](implementation-status.md).
