# Project roadmap

The roadmap tracks a deliberately incremental build. Check items only when evidence supports completion.

## Phase 0 — Documentation baseline
- [x] Repository documentation structure
- [x] Logical architecture draft
- [x] Initial security and publication policy
- [x] Validation and recovery templates
- [x] Project charter and inventory/evidence/change templates

## Phase 1 — Foundation
- [ ] Select host / hypervisor and document resources
- [ ] Establish isolated virtual networks
- [ ] Inventory assets and versions
- [ ] Document addressing and time synchronization
- [ ] Review host network isolation

## Phase 2 — Core services
- [ ] Select a minimal service scope
- [ ] Deploy selected systems services
- [ ] Record dependencies and service owners
- [ ] Validate access and name resolution
- [ ] Record service lifecycle and limitations

## Phase 3 — Segmentation and defensive controls
- [ ] Implement separated zones in the isolated lab
- [ ] Document intended traffic requirements
- [ ] Verify approved and prohibited flows using safe tests
- [ ] Review privileged access and hardening
- [ ] Document exceptions and review dates

## Phase 4 — Observability
- [ ] Collect infrastructure metrics
- [ ] Centralize selected logs
- [ ] Test alert delivery and acknowledgement
- [ ] Review coverage and collection gaps
- [ ] Record monitoring catalogue

## Phase 5 — Resilience
- [ ] Define backup scope and retention
- [ ] Perform isolated restoration exercise
- [ ] Measure and record recovery objectives
- [ ] Record lessons learned and recovery dependencies

## Phase 6 — Evidence and release
- [ ] Record test results and findings
- [ ] Retest remediation
- [ ] Sanitize screenshots and documents
- [ ] Review repository for secrets and sensitive content
- [ ] Align status and diagrams with observed reality
- [ ] Publish a project release / summary
