# Learning and build plan

This is a phased portfolio roadmap, not a claim that components are deployed.

## Stage A — Planning
- [ ] Define constraints, scope and safety boundary
- [ ] Select platform based on resources
- [ ] Inventory and architecture decision records

## Stage B — Foundation
- [ ] Isolated virtual networks
- [ ] Inventory and addressing documentation
- [ ] Basic system lifecycle documentation

## Stage C — Services
- [ ] Select and deploy a small set of services
- [ ] Document dependencies and baseline health
- [ ] Validate configuration in the isolated lab

## Stage D — Defensive controls
- [ ] Identity and privilege review
- [ ] Host security settings and patch management
- [ ] Segmentation documentation and safe validation
- [ ] Defensive event collection

## Stage E — Monitoring
- [ ] Baseline metrics and health checks
- [ ] Alert catalogue and delivery validation
- [ ] Dashboard and operating notes

## Stage F — Recovery
- [ ] Backup scope and policy
- [ ] Isolated restoration exercise
- [ ] Record measured recovery outcomes

## Stage G — Portfolio quality
- [ ] Evidence and findings register
- [ ] Documentation review
- [ ] Sanitization review
- [ ] Honest project summary and release
