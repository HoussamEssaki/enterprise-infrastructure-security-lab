# Lab maintenance checklist

A periodic review checklist; cadence should be adapted to the lab.

## Inventory and configuration
- [ ] Inventory reflects actual assets and versions
- [ ] Architecture and diagrams match the lab
- [ ] Configuration changes are recorded
- [ ] Unneeded assets and services are retired

## Security hygiene
- [ ] Updates and maintenance status reviewed
- [ ] Privileged access reviewed
- [ ] Secrets are not stored in repository
- [ ] Management access remains restricted
- [ ] Exceptions have rationale and review date

## Monitoring
- [ ] Monitoring coverage reviewed
- [ ] Alerts are actionable and routed
- [ ] Collection gaps and time synchronization reviewed
- [ ] Logs are stored with appropriate access and retention

## Recovery
- [ ] Backup status reviewed
- [ ] Restore exercise scheduled or completed
- [ ] Recovery notes updated from evidence

## Documentation
- [ ] Status labels reflect evidence
- [ ] Evidence sanitized
- [ ] Outstanding findings have owners or next steps
