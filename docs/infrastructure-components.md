# Infrastructure components

- **Compute / virtualization:** physical host, remote management, RAID, VMware ESXi and vCenter; resource constraints affected scale.
- **Network:** Cisco switching concepts covering segmentation, routing, redundancy, STP and link aggregation.
- **Perimeter:** FortiGate HA, boundary filtering, security profiles and logging.
- **Windows:** directory services, DNS, DHCP and Group Policy.
- **Linux / DMZ:** RHEL-based service environment.
- **Storage:** TrueNAS, ZFS and NFS.
- **Backup:** Veeam and cloud object-storage retention/immutability concepts.
- **Monitoring:** Zabbix and Grafana.
- **Security analytics:** Wazuh; Splunk exploration.
- **VoIP:** FreePBX/Asterisk and softphone tests.
- **Automation:** n8n with PostgreSQL; Ansible studied as a future direction.

This is a demonstrator, not a production architecture. Capacity, hardening, integration and evidence gaps remain documented.
