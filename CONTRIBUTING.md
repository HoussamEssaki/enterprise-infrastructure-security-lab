# Contributing

Thank you for helping improve this learning lab.

## Scope

Contributions should improve clarity, reproducibility, defensive security, documentation or validation quality. Keep all examples suitable for an isolated, authorized lab.

## Before opening a change

- Explain the purpose and scope.
- Keep steps reproducible and note tested versions where known.
- Distinguish proposed design from implemented and tested behaviour.
- Include sanitized evidence for claims about test results.
- Update the relevant documentation and status register.
- Check that no secrets, personal data or employer-confidential details are included.

## Documentation style

- Prefer concise headings, tables and diagrams.
- Explain assumptions and prerequisites.
- Include expected results and rollback notes for operational changes.
- Mark unverified content as planned or not tested.

## Safety

Do not submit instructions intended to disrupt systems, bypass access controls or target networks without authorization. This repository is for defensive learning in isolated environments.
