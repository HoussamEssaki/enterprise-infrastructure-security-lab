# Security Policy

## Scope

This repository documents a personal learning lab. It is not a production service and does not accept reports about third-party systems.

## Reporting a concern

If you find a secret, personal data or sensitive infrastructure detail in this repository, do not copy or redistribute it. Contact the repository owner privately through the GitHub profile contact channels and identify the affected file and commit.

For credentials that may have been exposed:
1. Revoke or rotate them immediately at the relevant provider.
2. Remove the secret from the current source and review repository history.
3. Check access logs and dependent services.
4. Do not rely on deleting a visible line as the only remediation.

## Supported scope

Security feedback should relate to this repository's documentation, example scripts or lab design. Only test systems you own or have explicit permission to assess.

## Safe publication

Never publish passwords, tokens, private keys, VPN configuration exports, real internal IP plans, personal data or confidential employer/client information.
